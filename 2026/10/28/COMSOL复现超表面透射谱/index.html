COMSOL复现超表面透射谱

发表于2026-10-28
|字数总计:4.5k|阅读时长:15分钟|阅读量:

3R-MoS₂ 非局域超表面 · COMSOL 6.4 中文界面 ·

0. 准备工作与整体思路

需要用到两个数据文件（点击下载）：

文件内容
n_MoS2_ref18.txtMoS₂ 折射率实部 n，来自论文参考文献 18（两列：波长 µm、·）
k_MoS2_FigS6.txtMoS₂ 消光系数 κ，从论文补充材料 Fig. S6 读取（两列：波长 µm、κ）

结构和坐标

超表面是一层 160 nm 厚的 MoS₂，刻成两根一宽一窄的线条，周期性排列在 SiO₂ 衬底上。线条沿论文的 y 方向无限长，所以我们只需要算它的横截面，也就是一个二维问题。

论文中的方向COMSOL 二维模型中的方向
x（周期方向）x（水平）
z（厚度方向）y（竖直）
y（沿线条方向）z（垂直于屏幕，面外方向）

物理原理：结构沿线条方向不变，光又是正入射，所以场沿这个方向也不变化，三维问题就退化成二维。论文的 y 偏振（电场平行于线条）在 COMSOL 里对应电场只有面外分量 Ez，即 TE 偏振。x 偏振对应电场在面内（Ex、Ey），即 TM 偏振。

计算思路

只画一个周期，左右边界设为周期性条件。光从顶部空气入射，底部用完美匹配层（PML）吸收透射光。最后在衬底里取一条水平线，对电场做周期平均，得到 0 级透射率。

1. 模型向导：建立二维频域模型

  1. 打开 COMSOL，在启动界面点 模型向导。

  1. "选择空间维度"界面，点 二维。

  1. 在物理场列表里依次展开 光学 → 波动光学，选中 电磁波，频域 (ewfd)。
  2. 点列表下方的 添加，它会出现在"添加的物理场接口"里。然后点右下角的 研究 →。


图 3：选中"电磁波，频域 (ewfd)"


图 4：点"添加"之后，下面出现了 ewfd；右侧显示它求解的是电场 E 的三个分量

  1. 在"一般研究"下选 频域，然后点左下角 完成。


图 5：选"一般研究 → 频域"，再点"完成"

物理原理："频域"是指每次只算一个确定频率（单色光）的稳态场，直接求解亥姆霍兹方程（Helmholtz equation）∇×(∇×E) − k₀²εrE = 0。要得到透射谱，就把频率一个个扫过去。它和 FDTD（时域有限差分）不同：FDTD 用一个脉冲一次覆盖很多波长，需要等场衰减完才能得到准确的频谱。频域方法没有这个问题，所以特别适合 Q 值很高、线宽很窄的共振。

界面认识 + 设置长度单位

点"完成"后进入主界面。左边是模型开发器（模型树，所有设置都在这里），中间是设置窗口（点哪个节点就显示哪个节点的设置），右边是图形窗口。

  1. 在模型树里点 几何 1，把设置窗口里的 长度单位 从 m 改成 µm。


图 6：主界面。选中"几何 1"，在"单位 → 长度单位"里改成 µm

  1. 点设置窗口顶部的 全部构建，再点图形窗口工具栏上的"缩放到窗口大小"，就能看到整个结构。


图 8：矩形 1（PML）的设置：宽度 P、高度 1、位置 (0, −3)


图 9：矩形 5（宽线条）的设置


图 10：构建完成的几何。从下往上依次是 PML、衬底（分成两块）、空气，两根线条在 y = 0 处

物理原理：
• 只画一个周期：根据布洛赫-弗洛凯定理（Bloch–Floquet theorem），周期结构里的场在相邻周期之间只差一个相位因子，正入射时这个相位为 0。所以算一个周期就代表了无限大的阵列，对应论文里"假设无限延伸"的计算。
• 衬底为什么分两块：中间的分界线 y = −1 µm 用来"测量"透射场，距离光栅 1 µm，足以让倏逝场（近场）衰减掉。
• 空气层 1.5 µm：让端口离光栅远一些，近场不会碰到端口。

注意：两根线条的位置要严格按表格填，间隙 G 一半在左边界、一半在两线之间。这是为了和论文的单元一致，周期性边界会把左右两半间隙拼起来。

4. 变量与材料色散

4.1 插值函数：导入 MoS₂ 的 n 和 κ

  1. 右键 组件 1 → 定义 → 函数 → 插值。
  2. 函数名称填 n_mos2。在表格下方点 从文件加载 的图标，选 n_MoS2_ref18.txt。
  3. "插值和外推"里把插值方式选 三次样条。
  4. 再建一个插值函数，名称 k_mos2，加载 k_MoS2_FigS6.txt，同样选三次样条。


图 11：插值 1，函数名 n_mos2。表格第一列是波长（µm），第二列是 n


图 12：插值 2，函数名 k_mos2，第二列是 κ（约 0.01）

4.2 变量

  1. 右键 组件 1 → 定义 → 变量，填入：
名称表达式含义
lam_umc_const/freq/1[um]真空波长（以 µm 为单位的纯数）
n_sio2sqrt(1+0.6961663*lam_um^2/(lam_um^2-0.0684043^2)+0.4079426*lam_um^2/(lam_um^2-0.1162414^2)+0.8974794*lam_um^2/(lam_um^2-9.896161^2))SiO₂ 折射率（Sellmeier 公式）
n_on_mos2(lam_um)MoS₂ 折射率实部
k_ok_mos2(lam_um)MoS₂ 消光系数


图 13：变量 1

物理原理：
• 色散：材料折射率随波长变化。freq 是 COMSOL 正在计算的频率，c_const 是光速，所以 lam_um 会随扫描自动变化，每个波长都用对应的 n、κ。
• SiO₂：用 Malitson 的 Sellmeier 色散公式，在 1.55 µm 处 n ≈ 1.444。
• κ 为什么这么关键：1550 nm 处 κ 只有约 0.01，看起来可以忽略。但 y 偏振的共振是一个准连续域束缚态（quasi-BIC），Q 值约 1760，光在结构里要来回振荡上千次，每次都被吸收一点，累积起来就和辐射损耗相当。κ = 0 时 y 谱是 T 从 0 到 1 的尖锐 Fano 线形；κ ≈ 0.01 时 Fano 峰被抹平，只剩论文图里那个小谷。

5. 积分算子与 PML

5.1 积分算子

  1. 右键 定义 → 非局部耦合 → 积分。
  2. "几何实体层"选 边界，然后在图形窗口点 y = −1 µm 那条水平线（边界 6），它会变蓝。
  3. "算子名称"改成 intline。


图 14：积分算子 intline，选中边界 6（图中蓝色的线，y = −1）

物理原理：透射光里除了直着往下走的 0 级，还可能有 ±1 级衍射（波长 < 1.444 × 1.06 ≈ 1.53 µm 时，±1 级能在衬底里传播）。±1 级的场沿 x 方向按 e±i2πx/Λ 振荡，在一个周期上积分正好为零。所以 intline(E)/P（周期平均场）只保留了 0 级，正好对应论文测的正向透射。

5.2 完美匹配层（PML）

  1. 右键 定义 → 完美匹配层，选择最下面的区域 1。


图 15：完美匹配层，区域 1

物理原理：真实衬底很厚，光进去就不会回来。PML 是一层人为设计的吸收材料，它的阻抗和衬底匹配，所以任何角度入射的光都不会被反射，进去后很快衰减到零，相当于"无限厚的衬底"。PML 内部的材料要和衬底相同（第 6 步会给它设成 SiO₂）。

6. 物理场：给每个区域设置折射率

展开 电磁波，频域 (ewfd)，下面已经自动生成了 波动方程，电 1，它作用在所有区域上且不能修改范围。我们先把它设成空气，再添加两个新节点"覆盖"衬底和线条区域。模型树里下面的节点会覆盖上面的节点。

注意：因为我们没有在"材料"节点里添加材料，每个"波动方程，电"节点里的折射率都必须手动改成用户定义，否则会报错"缺少材料属性"。

6.1 空气（波动方程，电 1）

  1. 点 波动方程，电 1，"电位移场模型"选 折射率。n 选 用户定义 填 1，k 选 用户定义 填 0（公式下方会显示 σ = 0、µr = 1，不用管）。


图 16：波动方程，电 1（全部区域）：n = 1，k = 0

6.2 SiO₂ 衬底 + PML（波动方程，电 2）

  1. 右键 电磁波，频域 → 波动方程，电，选区域 1、2、3（PML 和两块衬底）。
  2. n 选用户定义，填 n_sio2；k 填 0。


图 17：波动方程，电 2，区域 1、2、3，n = n_sio2

6.3 MoS₂ 线条（波动方程，电 3）

  1. 再添加一个 波动方程，电，选区域 5、6（两根线条）。
  2. n 选用户定义，填 n_o（各向同性）；k 选用户定义，填 k_o。


图 18：波动方程，电 3，区域 5、6（图中蓝色的两根线条），n = n_o，k = k_o

物理原理：COMSOL 用复折射率 ñ = n − iκ 来描述材料，相对介电常数 εr = (n − iκ)²。虚部 κ 代表吸收，光每传播一个波长，强度衰减 e−4πκ 倍。
这里把 MoS₂ 当作各向同性处理（面外折射率也用 n_o）。真实的 3R-MoS₂ 面外折射率约 3.15，比面内的约 3.9 低。y 偏振的电场只在面内，所以这个近似对它没有影响。x 偏振的场有面外分量，用各向同性近似时深谷落在 1.576 µm，和论文一致，说明论文也是这样算的。

7. 物理场：端口与周期性条件

7.1 端口（入射光）

  1. 右键 电磁波，频域 → 端口，选顶部边界 9（y = 1.5 µm）。
  2. "端口类型"选 周期性；"此端口的波激励"选 开。
  3. "端口模式设置 → 极化"选 线性极化，下面选 S；入射角 α 填 0。
  4. 设置窗口继续往下滚动，端口的折射率选项选 来自相邻域（即使用空气的 n = 1，这一项一般就是默认值）。


图 19：端口 1，边界 9，周期性端口，线性极化 S

物理原理：
• 周期性端口会发射一束平面波，同时自动计算反射回来的功率（S 参数 S11，反射率 R = |S11|²）。
• S 和 P 偏振：S（德语 senkrecht，垂直）指电场垂直于入射面，这里就是沿线条方向的 Ez，即论文的 y 偏振。P 指电场在入射面内，即论文的 x 偏振。
• 为什么从空气侧入射：论文实验是光从衬底侧入射。根据光学互易定理（reciprocity），同一对端口之间，正向和反向的 0 级透射率相同，所以从空气侧入射算出的 T 和论文一致。从空气侧入射的好处是：空气里只有 0 级衍射（λ > Λ），端口设置最简单。

7.2 周期性条件（左右边界）

  1. 右键 电磁波，频域 → 周期性条件，选左边界 1、3、5、7 和右边界 20、21、22、23（在图形窗口里点最左和最右的所有竖线段）。
  2. "周期性类型"保持默认的 连续性 即可。


图 20：周期性条件 1，左右两侧共 8 段边界（src = 源，dst = 目标），周期性类型"连续性"

物理原理：弗洛凯周期性条件（Floquet periodicity）要求右边界的场 = 左边界的场 × e−ikxΛ。正入射时 kx = 0，退化为左右场完全相等，也就是"连续性"类型，相当于把这一个周期无限复制下去。如果以后要算斜入射，就要改成"弗洛凯周期性"，k 矢量取自周期性端口。

8. 网格

  1. 点 网格 1，"序列类型"选 用户控制网格。
  2. 点 大小，"校准为"普通物理学，选 定制，最大单元大小填 0.08（µm）。
  3. 右键 网格 1 → 边，选左边界 1、3、5、7。
  4. 右键 网格 1 → 复制边，"源边界"选 1、3、5、7，"目标边界"选 20、21、22、23。
  5. 右键 网格 1 → 自由三角形网格；再右键它 → 大小，"几何实体层"选域，选区域 5、6，定制，勾选最大单元大小填 0.02。
  6. 点 网格 1 → 全部构建。


图 21：全局大小，最大单元 0.08 µm


图 22：边 1，左边界 1、3、5、7


图 23：复制边 1，从左边界复制到右边界 20–23


图 24：自由三角形网格下的大小 1，MoS₂ 区域 5、6 加密到 0.02 µm


图 25：构建好的网格，线条附近明显更密

物理原理：
• 有限元方法要求每个波长内至少有 5–10 个单元。介质里的波长是 λ/n：空气中约 1.5 µm，衬底约 1.0 µm，MoS₂ 里只有约 0.4 µm。全局取 0.08 µm，MoS₂ 里取 0.02 µm（每个波长约 20 个单元，160 nm 厚度方向约 8 个单元），足以把高 Q 共振的位置算准。
• 复制边让左右边界的网格节点一一对应，周期性条件才能精确地把左右节点配对，不会因为插值引入误差。

9. 研究：扫描波长并计算

  1. 点 研究 1 → 步骤 1：频域。
  2. "频率单位"选 Hz。
  3. "频率"一栏直接填：c_const/range(1.40,0.0005,1.85)[um]
  4. 点设置窗口顶部的 计算（或者右键研究 1 → 计算）。普通笔记本大约需要 1–2 分钟。


图 26：频域研究步骤。频率单位 Hz，频率列表用波长换算

说明：range(1.40,0.0005,1.85) 生成 1.40、1.4005、…、1.85 共 901 个波长（步长 0.5 nm），乘以 [um] 后用 c/λ 换算成频率。步长要足够细，否则会漏掉窄共振：κ = 0 时 y 共振的宽度不到 1 nm，步长 2 nm 就完全看不到它。

常见坑：如果"频率单位"是默认的 THz，表达式算出的 Hz 数值会被当成 THz，频率大了 10¹² 倍。结果表现为场全为零、R = 1。一定要改成 Hz。

10. 结果：画透射谱

  1. 右键 结果 → 一维绘图组，再右键它 → 全局。
  2. "y 轴数据"表格的表达式填（一整行）：

    (intline(n_sio2)/P)*abs(intline(pol*ewfd.Ez+(1-pol)*ewfd.Ex)/P)^2/(2*Z0_const)*P*1[m]/1[W]
  3. "x 轴数据"的参数选 表达式，填 c_const/freq，单位选 um。
  4. 点 绘制。


图 27：全局绘图设置和得到的 y 偏振透射谱

物理原理：透射率公式
透射率 = 透射功率 / 入射功率。对一个平面波，单位面积的功率（坡印廷矢量）是 S = n|E|²/(2Z₀)，其中 Z₀ ≈ 377 Ω 是真空波阻抗，n 是所在介质的折射率。所以：
T = nSiO₂ · |⟨E⟩|² / (2Z₀) × Λ × 1 m ÷ Pin
• intline(...)/P = 周期平均场 ⟨E⟩（只剩 0 级）；intline(n_sio2)/P 是那条线上的 nSiO₂。
• pol*ewfd.Ez+(1-pol)*ewfd.Ex：pol = 1 时取 Ez（y 偏振），pol = 0 时取 Ex（x 偏振）。x 偏振时在 y = −1 这条水平线上，0 级平面波的电场只有 x 分量。
• P*1[m]：二维模型默认面外厚度 1 m，乘周期就是端口截面积；1[W]：端口默认入射功率 1 W。

11. x 偏振与结果检查

计算 x 偏振

  1. 参数 1 里把 pol 改成 0。
  2. 端口 1 里把极化从 S 改成 P。
  3. 再点一次 计算，然后绘制。

想把两条线画在一张图里：先算 y 偏振，右键研究 1 生成一个新的解（或者复制一个研究 2），然后在同一个一维绘图组里加两个"全局"节点，分别选对应的数据集。初学时也可以分别导出数据（右键全局 → 添加到表格 / 导出），再用 Python 或 Origin 合并作图。

可以自己做的小实验（加深理解）：

  1. 把 MoS₂ 的 k 改成 0 重算 y 偏振，会看到 T 从 0 到 1 的尖锐 Fano 线形，峰谷只差约 0.9 nm（需要把 1.54–1.56 µm 的步长缩到 0.02 nm）。
  2. 把 w1 改成和 w2 一样（对称结构），共振会变成真正的 BIC（Q 值无穷大），在透射谱里完全消失。
  3. 把端口入射角 α 改成几度，看共振怎样随角度红移。这就是论文实测谱共振出现在 1.6–1.7 µm 的原因（物镜带来大角度入射）。
