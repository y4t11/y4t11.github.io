Python 学习笔记

发表于2026-11-04
|字数总计:2.6k|阅读时长:9分钟|阅读量:

跟着 CS50P 学 Python 时整理的笔记和踩坑，按主题持续追加。

正则表达式（re 模块）

正则表达式（regular expression，简称 regex）：一种描述“文本长什么样”的规则，用来检查、查找字符串。Python 里用 re 模块。

re.search：在整句里“找”

re.search(规则, 字符串) 会在字符串的任意位置找符合规则的一段，找到一段就算成功，返回匹配对象；找不到返回 None。

规则前面的 r 表示原始字符串（raw string），让反斜杠 \ 按原样传给正则，不被 Python 先转义。正则一律写成 r"..."；规则里本身有双引号时，外层改用单引号 r'...'。

^ 和 $：锁住开头和结尾

  • ^：这里必须是字符串的开头
  • $：这里必须是字符串的结尾

它们不匹配任何字符，只限定位置。两头都加（^...$）表示“整个字符串必须完全符合规则”。

规则字符串结果原因
^cat"my cat"失败cat 不在开头
cat$"category"失败cat 后面还有字符
^cat$"cats"失败结尾多了 s
^dog$"hotdog"失败开头是 hot
dog$"hotdog"成功只要求以 dog 结尾

类比：re.search 像一个在信号上滑动扫描的窗口，哪一段对上就报“找到了”；^ 和 $ 规定窗口只能对齐起点和终点，不准滑动。

踩坑：做“验证格式”类的题（比如判断 IP 地址合不合法）一定要加 ^...$。不加的话，"1.2.3.4.5" 里能找到一段 "1.2.3.4"，会被误判成合法。

常用符号速查

符号含义例子
.任意一个字符a.c 匹配 abc、a-c
\.真正的点youtube\.com
\d一个数字
+前一项重复 1 次或多次\d+ 匹配 7、2026
\d{1,3}1–3 位数字
?前一项可有可无https?、(?:www\.)?
(AM|PM)二选一
[^"]+一个或多个“不是双引号”的字符
\b单词边界（位置，不占字符）\bum\b 不匹配 yummy

踩坑：[0-255] 不是“0 到 255”

[...] 是字符集（character set），只匹配一个字符。[0-255] 的意思是“0–2、5、5 中的某一个字符”，所以 192 匹配不上。

原则：正则只管格式，数值大小交给 Python。 先用正则把每段数字取出来，再 int() 后比较。

分组与取值

写法含义
( ... )捕获组：匹配并记住这一段
(?: ... )只分组、不捕获，不占组号
m.group() / m.group(0)整个匹配
m.group(1)第 1 个捕获组（从 1 开始数）
m.groups()所有捕获组组成的元组，如 ('1', '2', '3', '4')
  • 捕获到的都是字符串，比大小前要 int()
  • 可选的组没匹配到时，取出来是 None

例子：可选的“冒号+分钟”

  • 外层 (?: ... )?：整体可有可无，不捕获
  • 中间 :：真正的冒号（所以会出现 (?:: 两个冒号连在一起）
  • 内层 (\d{2})：只捕获分钟数字
  • 写成 (:\d{2}) 会把冒号也捕获进去

踩坑：.+ 太贪婪

.+ 会尽可能多地匹配（贪婪，greedy）。比如用 src="(.+)" 取链接，会把后面的 " title=... 也吞进去。

解决：限定字符范围，比如 ([^"]+)（遇到双引号就停）或 ([a-zA-Z0-9_-]+)。

re 常用函数

函数作用
re.search(p, s)找第一个匹配，返回匹配对象或 None
re.findall(p, s)找所有匹配，返回列表，len() 就是次数
re.IGNORECASE作为第三个参数传入，忽略大小写

Python 写法

海象运算符 :=

等价于先 m = re.search(...) 再 if m:，一边赋值一边判断。

“全部满足才返回 True”

  • 常见错误：在循环里写 else: return True，检查完第一个就返回了
  • return 会立刻结束整个函数

主动抛错 raise

  • 和 return 一样会立刻结束函数，但表示“出错了”
  • 不要用 try / except ValueError: pass 包住自己的 raise，错误会被吞掉，函数悄悄返回 None
  • 正则没匹配上时也要 raise，否则同样悄悄返回 None

先校验，后转换

把输入转换成别的形式（比如 12 小时制转 24 小时制）之前，先检查原始输入是否合法。先转换再检查，0 AM、13 AM 这类非法输入可能变成看起来合法的值，被放过去。

先处理 None

先 int(minute) 再判断会报 TypeError，因为 int(None) 不合法。

补零格式化

:02 表示宽度 2、不足补 0，只对数字生效。

返回多个值 → 解包

不要写 to_24(...)[0], to_24(...)[1]，那样同一个函数被调用了两次。同样的规则要用两次（比如开始时间、结束时间）时，就把它拆成一个辅助函数。

12 小时制规则

12 小时制24 小时制
12:xx AM00:xx
1–11 AM不变
12:xx PM12:xx（不加 12）
1–11 PM+12

小时的合法范围是 1–12，没有 0 点。

踩坑：中文标点

SyntaxError: invalid character '：' (U+FF1A)：代码里混进了全角中文冒号。写代码时切到英文输入法。

面向对象（OOP）

OOP（object-oriented programming，面向对象编程）：用 class（类）定义一种新类型，把数据和处理数据的函数打包在一起。

方法与 self

  • 写在 class 里的函数叫方法（method），本质上还是函数，只是属于对象。
  • 方法的第一个参数固定写 self，指“当前这个对象自己”。调用时不用手动传，Python 会自动把对象本身塞进去。
  • 所以 __init__(self, name, house, patronus) 在调用时只需要传 3 个参数：Student("Harry", "Gryffindor", "Stag")。

__init__ 和 __str__

前后带双下划线的方法叫“魔术方法”（dunder method，double underscore 的缩写）：名字是 Python 规定好的，一般不自己调用，Python 在特定时机自动调用。

__init____str__
何时被调用创建对象时：Student(...)对象被当成字符串用时：print(s)、str(s)、f-string
作用初始化：校验参数，把数据存进 self决定对象打印出来长什么样
返回值不写 return（返回 None）必须 return 一个字符串

不写 __str__ 时，print(s) 只会输出 <__main__.Student object at 0x7f...> 这样的内存地址。

一句话：方法就是属于对象的函数；__init__ 管“创建时怎么初始化”，__str__ 管“打印时显示什么”。

pytest 测试

基本写法

运行：pytest test_working.py

测试是用来抓错误版本的

先想“一个写错的函数可能错在哪”，再为每种错误写一条 assert。CS50 的 check50 会准备几个故意写错的版本，看你的测试能不能发现它们，比如：

  • 只检查了 IP 的第一段 → 测试里要有后几段越界的例子（如 1.1.1.256）
  • 段数多了也接受 → 要有 1.2.3.4.5
  • 该报错没报错 → 要有 pytest.raises

覆盖清单：正常情况 · 边界值（0、255、12 AM/PM）· 格式错误 · 越界 · 可选部分有和没有。

退出码 5

check50 报 expected exit code 0, not 5：pytest 一个测试都没找到，通常是测试文件是空的，或者函数名没以 test_ 开头。

Git

基本流程

git add . ':!numb3rs'：添加所有文件，但排除 numb3rs。

remote add 和 remote set-url

  • git remote add origin 地址：新建远程；名字已存在会报 remote origin already exists
  • git remote set-url origin 新地址：修改已有远程的地址

not a git repository 是正常报错

fatal: not a git repository 说明 git 能用，只是当前目录还不是仓库，和“git 被禁用”是两回事。

CS50 Codespace 环境

工作区禁用 git

在 CS50 工作区 /workspaces/<编号> 及其子文件夹里运行 git，会提示 Git is disabled。工作区本身是 CS50 管理的仓库（submit50 要用）。

解决：在主目录 ~ 里建自己的仓库，作业写完后复制过去。

位置用途
/workspaces/<编号>写代码、check50、submit50（git 禁用）
~/cs50p自己的 git 仓库
  • ~ 里有 .ssh 等密钥和凭证，不要把整个 ~ 建成仓库上传
  • Codespace 重建后 ~ 里的内容可能丢失，代码要及时 push
  • CS50 学术诚信规定不能公开作业答案，作业仓库要设成 Private

作业备份流程

改过的题要重新 cp 覆盖；~/cs50p 丢了就 git clone 回来。

check50 连不上：看 debug 日志

依次排查了网络（curl -sI https://github.com）、git 配置、令牌、换目录、重启 Codespace，都没问题。最后用

看到 504 Gateway Time-out（网关超时）：是 GitHub 服务端的问题，只能等恢复。

经验：排查时尽早看 debug 日志，比逐个猜原因快得多。
